# ⚡ 高速网络扫描器

快速发现局域网内的开放端口和服务。

## 🚀 快速开始

### 方式一：在线使用（GitHub Pages）

直接访问：https://peng456.github.io/network-scanner/

**特点**：无需安装，直接在浏览器扫描（较慢）

### 方式二：快速扫描（需要 Node.js）

```bash
# 克隆仓库
git clone https://github.com/peng456/network-scanner.git
cd network-scanner

# 安装依赖
npm install

# 启动服务器
npm start

# 访问
# http://localhost:3334
```

**特点**：TCP 原生扫描，快 10 倍，1-2 分钟完成整个网段

## 📋 功能

- ✅ 快速扫描整个子网（254 个 IP）
- ✅ 支持单个 IP、IP 范围、全网段扫描
- ✅ 支持单个端口、端口范围、全端口扫描
- ✅ 实时显示扫描进度和发现的服务
- ✅ 直接点击访问发现的服务
- ✅ 超激进并发（500+）

## 💻 需求

- 浏览器（Chrome/Firefox/Safari）
- Node.js 14+ （可选，用于快速扫描）

## 🎯 使用场景

- 发现局域网内的隐藏服务
- IP 变动时快速定位服务
- 开发测试环境服务发现

## 📝 使用示例

| 场景 | IP | 端口 | 说明 |
|------|---|------|------|
| 找单个 IP 的开放端口 | `192.168.1.100` | `all` | 扫描该 IP 的全部 65535 端口 |
| 找整个网段的某个端口 | `192.168.1.*` | `43127` | 扫描 254 个 IP 的 43127 端口（快） |
| 找特定端口范围 | `192.168.1.*` | `8000-9000` | 扫描所有 IP 的 8000-9000 端口 |

## ⚡ 性能

| 扫描范围 | 浏览器扫描 | 服务器扫描 |
|---------|----------|----------|
| 1 IP × 1 端口 | <1s | <1s |
| 254 IP × 1 端口 | 2-5 分钟 | 30 秒 |
| 1 IP × 1000 端口 | 2-5 分钟 | 2-3 分钟 |

## 🔧 配置

编辑 `scanner-ws.js` 调整超时时间和并发数。
